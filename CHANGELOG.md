# Changelog

All notable changes to Blast Radius are documented here.

## 1.0.0 - 2026-08-16

### Added

- First stable release.
- Read-only `blast-radius:analyze` skill for pre-implementation change-impact analysis.
- Dedicated forked repository-analysis subagent restricted to `Read`, `Grep`, and `Glob`.
- Change-surface mapping with Direct / Likely / Watch confidence labels.
- Dependency-chain and cross-module contract analysis.
- Test-impact discovery and minimal missing-test recommendations.
- Risk register covering compatibility, migration, state, security, concurrency, and performance concerns.
- Safe implementation ordering and explicit unknowns.
- Self-hosted Claude Code marketplace manifest for `Garb-in-PacK/blast-radius`.
